# 小狄氧舱账号维护智能机器人 · 极简拍摄模板库（单人手机10分钟搞定）

10条脚本需均匀分布于以下 **5大爆款模型（每种2条）**：

1. **模型A：本地热点/天气蹭流型（2条）**
   - 机位：老板站在门店门口或窗边拍外面天气，转身走向氧舱。
   - 结构：本地天气/热点事件切入 → 引发身体体感共鸣 → 进店躺舱对比 → 引导同城体验。
2. **模型B：安全对比/反常识科普型（2条）**
   - 机位：手机怼拍氧舱细节（24V灯带、10.1寸触摸屏、水冷出风口、UPS铭牌）。
   - 结构：抛出消费者最担心的安全顾虑（“这玩意关里面停电怎么办？”） → 实拍演示狄耐克安全设计 → 建立“氧舱界沃尔沃”信任。
3. **模型C：沉浸实拍/真实体感型（2条）**
   - 机位：第一视角推开舱门、躺上沙发、点击触摸屏升压、切出舱后精神状态。
   - 结构：真实体验时间线（第10分钟/第30分钟/出舱） → 展示静音与舒适度 → 邀请评论区预约免费试躺。
4. **模型D：高端案例/信任背书型（2条）**
   - 机位：老板坐姿口播 + 手机画面叠加全国案例图（上市公司/别墅会所/世界冠军推荐）。
   - 结构：“为什么越来越多上市公司老板/别墅业主都在装这个？” → 借势狄耐克300884上市背景与真实案例 → 吸引B端/高净值C端咨询。
5. **模型E：特定人群痛点直击型（2条）**
   - 机位：门店日常场景，针对“失眠上班族 / 应酬酒局老板 / 跑马运动党 / 家里长辈”定向喊话。
   - 结构：精准点名人群 → 说出对方昨晚/今天的真实难受瞬间 → 给出60分钟躺平方案 → 引导同城私信领体验券。
